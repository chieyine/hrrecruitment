## Corrections made during this reconciliation

- Added the controlled assessment-question bank instead of redirecting its page elsewhere.
- Added assigned assessment reviewers and independent result approval before ranking.
- Added executable late-submission and accommodation timing rules.
- Added interview type, mandatory safeguarding questions and maker–checker panel approval, including bulk scheduling.
- Added immutable candidate-document versions and an HR verification screen.
- Expanded talent-pool records, consent expiry, roster expiry and scheduled expiry handling.
- Made scheduled delivery support the same 35 reports as manual export.
- Added daily notification digests and question-bank review/expiry processing.
- Replaced the false source-of-application calculation with a recorded application source.
- Added the complete analytics filter set and further conversion, source, cost and ERP measures.
- Corrected seed password hashing from bcrypt cost 10 to cost 12.
- Added a migration with explicit backfills for legacy source, consent, document versions, assessment approvals, interview panels and talent rosters.
- Retired the authenticated referee role while retaining referee records and expiring reference links.
- Added notification preferences so urgent messages stay immediate and routine messages can be digested.
- Applied the single-HR-manager approval policy to HR-owned vacancies and HR-created interview panels.
- Added external-course completion by certificate upload, with HR approval or replacement request.
- Confirmed formal offers support either an online signature or download, offline signature and secure PDF re-upload.
- Hardened first-touch application-source attribution so malformed client cookies fall back safely instead of interrupting an application.
- Re-checks the schedule owner's active account and current report permissions before every scheduled report delivery, so revoked access does not keep exporting data.
